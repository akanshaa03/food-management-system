# 🍽️ AI-Based Food Redistribution System

An AI-powered food redistribution platform that helps businesses reduce food waste by tracking inventory, predicting surplus food, and connecting businesses with NGOs for efficient food redistribution.

---

## 📌 Features

- 📦 Inventory Management
- ⏰ Expiry Date Tracking
- 🤖 AI Waste Prediction
- ❤️ Food Donation Management
- 🏢 Business Dashboard
- 🤝 NGO Dashboard
- 📊 Analytics & Reports
- 🔔 Notifications

---

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/akanshaa03/food-management-system.git
```

### Backend

```bash
cd backend
npm install
npm start
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### AI Service

```bash
cd ai-service
pip install -r requirements.txt
python app.py
```

---

## 🔑 Environment Variables

Create a `.env` file inside the `backend` folder:

```env
PORT=5000

DB_HOST=localhost
DB_PORT=5432
DB_NAME=food_redistribution_db
DB_USER=postgres
DB_PASSWORD=your_password

JWT_SECRET=your_secret
```
